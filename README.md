# Learning Rust

One repo for everything I do while learning Rust. Each course/book gets its own
top-level folder, and each Rust project inside it is its own Cargo crate.

See [PROGRESS.md](PROGRESS.md) for the full day-by-day log.

## Repo layout

| Folder | Source |
|---|---|
| [`rust_book/`](rust_book) | [The Rust Programming Language](https://doc.rust-lang.org/book/) ("the book") |
| [`100_exercises/`](100_exercises) | [100 Exercises to Learn Rust](https://rust-exercises.com/100-exercises/) |

New courses just get added as another top-level folder — no branches.
